# 亲子日常英语

252 句亲子日常英语，按一天的作息和常见场景编排，**点任意一句就会朗读**。

👉 **[打开页面](https://hljuanwh.github.io/daily-english-with-baby/)**

## 功能

- **点句朗读** —— 点一行即用浏览器语音读出英文
- **中 → 英 练习模式** —— 左中文、右英文，英文默认遮住；看着中文自己译一遍，点开对答案。「重新盖上」可再刷一轮
- **会了** —— 每行末尾的圆圈勾一下，这句就沉到本模块最下面并变淡，标记记在本机，刷新和关掉都还在；模块标题上显示「3/11 会了」
- **连读** —— 按模块顺序自动读下去，会自动跳过已标「会了」的句子；睡前故事尤其适合
- **语速 / 口音** —— 语速 0.5×–1.15×，美式 / 英式 / 澳式
- **搜索** —— 中英文都能搜

## 内容

一天的作息：起床、穿衣、洗漱、吃饭、玩耍、出门、洗澡、睡觉（含睡前故事《小熊不想睡觉》中英对照）。

场景与情绪：情绪安抚、表扬鼓励、规则与安全、亲子阅读、如厕、在外游玩（动物园 / 海洋馆 / 水上乐园 / 室内游乐场）、其他，以及 10 句高频万能句式。

**按绘本背（每册一个单元）**：欢唱童谣 Sing Along 12 册、ABC 冰淇淋 Alphabet Ice Cream 4 册、小手乐翻天 Busy Fingers 15 册各自拆到分册；古力小超人、Petr Horáček 纸板书、抽拉童谣暂为合并单元，待补分册书名。

导航是两级的：上面一行选分区（日常场景 / 各套书），下面一行是该分区的分册，点一下跳过去。搜索时跨分区全局搜。

绘本单元收录的是**读这册书时用得上的互动话术、可迁移的核心句型和指认句**，以及公版经典童谣的歌词；不收录在版绘本的正文。

## 说明

- 单个 `index.html`，无依赖、无构建、无第三方脚本，离线也能用（朗读依赖系统语音）
- 朗读用浏览器内置的 Web Speech API，iOS Safari 和 Chrome 都支持
- 中文只是给大人对照的，跟宝宝说的时候不用逐句翻译
- 一次固定 3–5 句，用两周成为肌肉记忆，再加新的
